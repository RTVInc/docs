IDS Prediction API v2

Predicts household agriculture value (USD) for Year One and Year Two from household survey JSON input. Used internally by the IDS to generate production projections for village design.

REST API Base URL: ids.api.nonproftinnovations.io Content-Type: application/json Authentication: None

Endpoints

MethodPathDescription
POST/predict/v2/Create a prediction — returns Year 1 and Year 2 agriculture value projections
GET/predict/v2/get-all-predictionList all predictions with inputs, outputs, and metadata
GET/predict/v2/logsList prediction logs (newest first)

POST /predict/v2/

POST https://ids.api.nonproftinnovations.io/predict/v2/

Submits household data and returns Year 1 and Year 2 agriculture value predictions. Two models are available: Regional (include region in payload) and General (omit region).

The regional model was trained with region as a feature. When projecting outside supported regions, omit region to use the general model instead.

Example — Regional model

curl -X POST "https://ids.api.nonproftinnovations.io/predict/v2/" \
  -H "Content-Type: application/json" \
  -d '{
    "region": "east",
    "implementation_type": "Replication",
    "Land_size_agriculture": 2.5,
    "hoes_tools": 1,
    "Beans_total_yield": 80
  }'

Example — General model

curl -X POST "https://ids.api.nonproftinnovations.io/predict/v2/" \
  -H "Content-Type: application/json" \
  -d '{
    "implementation_type": "Standard",
    "Land_size_agriculture": 1.8,
    "Maize_total_yield": 120
  }'

Response

{
  "id": 14,
  "prediction_year_one": 153.90,
  "prediction_year_two": 634.02,
  "region": "east",
  "implementation_type": "Replication",
  "created_at": "2026-05-25T12:06:39Z"
}

GET /predict/v2/get-all-prediction

GET https://ids.api.nonproftinnovations.io/predict/v2/get-all-prediction

Returns a JSON array of all predictions. Each record includes the original request payload plus prediction_year_one, prediction_year_two, id, and created_at. General-model predictions have "region": null.

GET /predict/v2/logs

GET https://ids.api.nonproftinnovations.io/predict/v2/logs

Returns prediction logs, newest first.

Log response fields

created_atISO 8601 stringTimestamp of the prediction

prediction_idintegerID of the associated prediction record
prediction_year_onenumberPredicted agriculture value — Year 1 (USD)
prediction_year_twonumberPredicted agriculture value — Year 2 (USD)
request_payloadobjectThe original input sent to the model
messagestringWhich model was used, e.g. "Prediction created (regional model)"
