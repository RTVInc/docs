Backend API / Swagger

The Implementation backend exposes Swagger UI for each of its 11 Laravel microservices, auto-generated by the l5-swagger package. All endpoints are documented with request parameters, response schemas, and example payloads.

Staging Swagger docs are available on the staging server. For local development, Swagger is available on localhost after running make run — see the Developer Setup guide for local URLs. Production API gateway: https://92mfti4b-gateway.nonproftinnovations.io/
