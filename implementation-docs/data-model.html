DataMongo Service

MongoDB analytics_db

A read-optimised MongoDB analytics layer. Unlike the other services, DataMongo owns no primary schema — instead it mirrors data from all other services into MongoDB collections for bulk exports, reporting queries, and performance-sensitive reads. Its migrations only add indexes to those collections.

There are no SQL entity tables in this service. The following collections are indexed for analytics and export workloads.

All documents are identified by the same guid used in the originating service's MySQL database. Relationships between documents follow the same guid-based conventions described in each service's ER diagram above.

agric_distributions
Mirrored from Agric — all distribution events
training_households
Mirrored from Training — household attendance
training_reports
Mirrored from Training — session summaries
households
Mirrored from Profiles — household profiles
received_household_seeds
Mirrored from Agric — seed receipts
vsla_members
Mirrored from VSLA — member records
