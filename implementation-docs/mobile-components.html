RTVButton

lib/ui/shared/design_system/rtv_button.dart

The single button component for all interactive actions. Returns a Future from onPressed to auto-manage loading state — callers don't need their own _isSubmitting flag. All variants are sized to RTVFieldMetrics.height to align with adjacent inputs.

FactoryDescription
RTVButton.primary()Dark teal fill, white text. Use for the main action on a screen.
RTVButton.secondary()Outlined, transparent fill. Use for secondary / cancel actions.
RTVButton.fullWidth()Stretches to container width. Use in forms and bottom-of-screen CTAs.
RTVButton.disabled()Gray fill, non-interactive. Prefer passing onPressed: null instead.
 
// Auto-loading state from async onPressed
RTVButton.primary(
  label: 'Submit report',
  onPressed: () async {
    await _submitReport();  // button spins until this completes
  },
)

// Force loading from external state
RTVButton.primary(
  label: 'Syncing…',
  isLoading: _isSyncing,
  onPressed: null,
)

RTVAlert

lib/ui/shared/design_system/rtv_alert.dart

Standard confirm/feedback dialog. Four semantic types with matching icon, badge tint, and action button color. Use RTVAlert.confirm() for decisions and RTVAlert.notify() for informational feedback.

TypeIcon colorAction buttonUse for
RTVAlertType.error#910E17#C1121FDestructive actions, failures
RTVAlertType.warning#F08355#F08355Risky or irreversible actions
RTVAlertType.success#7B9755#5D7B36Confirmations of successful actions
RTVAlertType.info#015158#015158Neutral information or prompts
 
// Confirm — returns true if user pressed the primary action
final confirmed = await RTVAlert.confirm(
  context,
  type: RTVAlertType.warning,
  title: 'Discard this report?',
  message: 'The details you entered will be lost.',
  confirmLabel: 'Discard',
);
if (confirmed == true) _discardReport();

// Notify — no return value, just informs
await RTVAlert.notify(
  context,
  type: RTVAlertType.success,
  title: 'Report submitted',
  message: 'Your training report has been saved.',
);

RTVInput / RTVInputDecoration

lib/ui/shared/design_system/rtv_input.dart

Input decoration presets for all TextFormField and TextField widgets. All presets delegate to RTVFieldMetrics so every field is exactly the same height as buttons and selects beside it.

PresetUse
RTVInputDecoration.standard()Default bordered input field
RTVInputDecoration.textArea()Multi-line text areas
RTVInputDecoration.success()Green border for valid state
RTVInputDecoration.warning()Amber border for warning state
RTVInputDecoration.error()Red border + error text for invalid state
 
TextFormField(
  controller: _nameCtrl,
  decoration: RTVInputDecoration.standard(hintText: 'Full name'),
)

// With error state
TextFormField(
  decoration: RTVInputDecoration.error(
    hintText: 'Phone number',
    errorText: _phoneError,
  ),
)

RTVAppBar

lib/ui/shared/design_system/rtv_app_bar.dart

Top app bar used on all primary screens. Shows last sync time, notification badge, and an offline pill automatically when connectivity is lost. The pill renders nothing while online — safe to include on all screens.

PropTypeDescription
lastSyncTimeString?Shown as "Last sync: …" unless isSyncing is true, in which case rendered verbatim as a progress message
notificationCountintBadge count on the notification icon (0 hides the badge)
isSyncingboolSpins the sync icon continuously
showConnectivityBadgeboolDefaults to true — opt out only where the header has no width to spare
actionsList<Widget>?Extra trailing widgets appended after the built-in actions
bottomPreferredSizeWidget?Widget pinned below the bar (e.g. a tab bar)

RTVBottomNav

lib/ui/shared/design_system/rtv_bottom_nav.dart

RTVUnderlineTabBar

lib/ui/shared/design_system/rtv_tab_bar.dart

Tabs with a 0.69 dp teal bottom border. Each tab fills equal width. Supports an optional count badge per tab (used in Workplans). Automatically switches between fixed-width and scrollable layout when tab labels exceed the available width.

RTVUnderlineTabBar(
  currentIndex: _tabIndex,
  onTap: (i) => setState(() => _tabIndex = i),
  tabs: const [
    RTVUnderlineTab(label: 'All households', count: 142),
    RTVUnderlineTab(label: 'Pending',         count: 17),
    RTVUnderlineTab(label: 'Completed'),
  ],
)

RTVGap

lib/ui/shared/design_system/rtv_gap.dart

Replace SizedBox(height: X) with semantic gap constants. RTVGap.horizontal.* gives the equivalent horizontal variant.

  children: [
    RTVText.h5('Section title'),
    RTVGap.xsm,          // 24 dp vertical
    SomeContentWidget(),
    RTVGap.sm,           // 32 dp vertical
    RTVButton.primary(label: 'Continue', onPressed: _next),
  ],
)

Row(
  children: [
    Icon(Icons.person_outlined),
    RTVGap.horizontal.xxxsm,  // 8 dp horizontal
    RTVText.label('Officer'),
  ],
)

RTVPressScale

lib/ui/shared/design_system/rtv_press_scale.dart

Wraps any tappable widget so it scales to 0.93 on press and springs back on release. Uses a Listener so pointer events pass through to the wrapped button — the child's onPressed still fires normally.

RTVPressScale(
  child: GestureDetector(
    onTap: _openCard,
    child: HouseholdCardWidget(household: h),
  ),
)

RTVBreakpoints

lib/ui/shared/design_system/rtv_breakpoints.dart

Responsive layout helper. RTV phone reference frame is 428 dp (Figma). Phone layout is ≤480 dp; tablet is ≥600 dp.

Constant / MethodValueUse
RTVBreakpoints.kCompactPhone360 dpGalaxy S / baseline small phones
RTVBreakpoints.kLargePhone428 dpFigma reference (RTV)
RTVBreakpoints.kPhoneMax480 dpPhone layout upper bound
RTVBreakpoints.kTablet600 dpTablet layout lower bound
RTVBreakpoints.isPhone(context)<480 dpSwitch to single-column, reduced gutters
RTVBreakpoints.isCompactPhone(context)<400 dpTightest layouts for small Android devices
 
// Column count varies by screen size
final cols = RTVBreakpoints.isPhone(context) ? 1 : 2;

// Value helper for any number of breakpoints
final padding = RTVBreakpoints.value(
  context,
  phone: 16.0,
  tablet: 24.0,
  desktop: 32.0,
);

lib/ui/shared/design_system/rtv_form_field.dart

Single source of truth for all report form inputs. All fields are RTVFieldMetrics.height tall so labels, text inputs, and selects line up on the same baseline.

WidgetDescription

RTVFieldLabelUn-numbered variant of the field label
RTVFormTextFieldFull-height text input with teal border, optional keyboard type
RTVSelectFieldSingle-select dropdown at field height
RTVMultiSelectFieldMulti-select dropdown with chips for selected items

  const RTVFormSectionHeader('Attendees'),
  const RTVNumberedLabel(1, 'Number of men'),

RTVSearchField

lib/ui/shared/design_system/rtv_search_field.dart

Standardized search box for all list filters. Same height as form fields. Supports optional clear (✕) button when the field has text. Used in workplans, report histories, household pickers.

RTVSearchField(
  hint: 'Search workplans',
  controller: _searchCtrl,
  onChanged: (q) => setState(() => _query = q),
  onClear: () {
    _searchCtrl.clear();
    setState(() => _query = '');
  },
)

RTVChoiceQuestion

lib/ui/shared/design_system/rtv_choice_question.dart

A complete choice question widget: prompt label above, options (chips or dropdown), validation error below. Comes in single-select and multi-select variants. Report forms use these through CheckinFormMixin which adds preview-ledger recording on top.

RTVSingleChoiceQuestion<String>(
  label: 'Preferred language',
  placeholder: context.tr('selectAnOption'),
  value: _language,
  options: languages,
  labelOf: (l) => l,
  errorMessage: context.tr('pleaseSelectALanguage'),
  onChanged: (l) => setState(() => _language = l),
)

RTVMultiChoiceQuestion<Topic>(
  label: 'Topics covered',
  values: _selectedTopics,
  options: allTopics,
  labelOf: (t) => t.name,
  onChanged: (topics) => setState(() => _selectedTopics = topics),
)

RTVFilterSelect

lib/ui/shared/design_system/rtv_filter_select.dart

Inline filter sitting inside a dashboard section header. Not a form field — no border or box. Opens a menu of string options on tap. Sizes to its caption; wrap in Flexible inside a Row to allow ellipsis.

Row(children: [
  RTVText.h6('Household attendance'),
  const Spacer(),
  Flexible(
    child: RTVFilterSelect(
      value: _selectedMonth,
      options: _months,
      onSelected: (m) => setState(() => _selectedMonth = m),
      placeholder: 'All months',
      placeholderFor: 'all',
    ),
  ),
])

RTVEmptyState

lib/ui/shared/design_system/rtv_empty_state.dart

Empty-state placeholder used inside dashboard cards when a chart, list, or table has no data. Figma node 8261:15249. Pass withCard: false when the widget is already inside a card and you only need the centered content.

RTVEmptyState(
  icon: Icons.bar_chart_outlined,
  title: 'No training data',
  description: 'Training reports will appear here once submitted.',
)

// Inside an existing card
RTVEmptyState(
  withCard: false,
  icon: Icons.checklist_rounded,
  title: 'No workplans',
  description: 'Workplans created this week will appear here.',
)

RTVMessageCallout

lib/ui/shared/design_system/rtv_message_callout.dart

The shaded coaching-message block inside questionnaire screens. Soft teal wash (RTVColors.surfaceMessage), solid 3 dp left rule in borderPrimary. Renders the message in quotes as something said to the household, not as app copy.

RTVMessageCallout(
